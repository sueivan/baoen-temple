# Bao'en Temple (報恩寺)

A single-file 3D virtual temple walk, built with three.js. Walk through the gate, climb the steps, and enter the Great Hall (大雄寶殿) to see Shakyamuni Buddha with Kasyapa and Ananda.

Languages: Traditional Chinese, Simplified Chinese, English (switch with the globe button, top right).

## Run

Open `index.html` in a browser (internet needed: three.js loads from cdnjs).

For GitHub Pages: push this folder to a repo, then Settings, Pages, deploy from the main branch.

## Controls

- Move: drag on the screen, or WASD / arrow keys
- Buttons at the bottom: palms together, bow, wooden fish, prayer beads
- The hall doors open when you walk up to them
- Top right: sound, language, light / dark UI
