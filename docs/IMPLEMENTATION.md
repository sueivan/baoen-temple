# 手機簡易版的實作範圍

保留原有寺院和人物，以手機觸控為主要操作方式；不加入帳號、多人連線、聊天、背包、任務、排行榜或付費功能。

- 主畫面僅保留聲音、選單、搖桿、回山門與四種靜心互動。
- 視角自動跟隨人物，沒有另外的電腦版介面。
- 模型由程式建立；靜態物件合批，門扇與人物獨立保留動畫。
- 行走分成小步，依山門、石階、殿門及柱子邊界逐步判斷。
- 語言、音效及省電偏好只存在本瀏覽器；儲存受限時沿用本次狀態。
- 動作期間暫停移動；切到背景時暫停動畫與聲音。
- PWA 使用相對網址，支援 GitHub Pages 倉庫子路徑。
- 保留原始 Three.js r128 並隨專案分發，無需第三方 CDN。

驗證依據與未驗證範圍見 `VERIFICATION.md`。
