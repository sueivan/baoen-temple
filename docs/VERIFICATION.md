## GitHub 部署後的簡短驗收

1. 用手機開啟網站，確認可進入庭院且沒有文字重疊。
2. 拖曳搖桿走過山門、庭院與石階，放開後立即停止。
3. 靠近大殿，等門打開後進入；確認不能穿過柱子或前牆。
4. 各按一次底部四個動作，再確認可以行走。
5. 開啟音效，確認木魚音量適中；切換其他 App 再回來不會自行行走。
6. 加入主畫面後開啟；確認成功載入並快取後，再以飛航模式測試。
